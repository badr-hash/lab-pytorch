# Laboratoire PyTorch

Travaux pratiques en Python et PyTorch pour explorer les bases de l’apprentissage profond, de la manipulation des tenseurs à l’entraînement de modèles de régression et de classification.

## Commencer

Le notebook [PyTorch — l’essentiel du framework](activietepratique_elhannakbadr.ipynb) présente les tenseurs, l’autograd, les fonctions de coût, les optimiseurs, les boucles d’entraînement et la sauvegarde des modèles. Il comprend des exercices de régression et de classification.

Les autres notebooks du dépôt sont [lab1.ipynb](lab1.ipynb) et [reg.ipynb](reg.ipynb). Des fichiers de poids sont également présents à titre de ressources du laboratoire.

## Environnement

Le fichier [pyproject.toml](pyproject.toml) indique Python 3.12 ou plus et les dépendances du projet. Ouvrir les notebooks dans un environnement Jupyter adapté et suivre les instructions de leurs cellules. Certaines cellules peuvent télécharger des données ou nécessiter des outils supplémentaires, notamment Graphviz. Une connexion internet peut être nécessaire.

Ce dépôt rassemble des exercices pédagogiques ; les résultats et les étapes d’installation n’ont pas été vérifiés dans un environnement neuf.
